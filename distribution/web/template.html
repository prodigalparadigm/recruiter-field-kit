Fieldwork · Prodigal Paradigm

Most AI-era reqs are more than one job.

Bundled into one seat, at a rate that prices one of them. Three tools to find out — decode the req, get the searches, score the person — in whatever AI assistant you already use. Free account is fine. Nothing to install.

1Start here

Decode the job description

How many jobs are actually in the req, which labour market each one lives in, who you are looking for, ten-minute screening questions with a real answer and a bluff, and a verdict with an email you can send the client.

The decoder

{{DECODE}}

Paste this into any AI assistant, then paste the job description underneath it in the same message.

2Same chat, after the decode

Get the searches

One Boolean string per labour market — tight, wide, and an exclusion clause — plus x-ray strings for a free account, what the same person is called at an enterprise versus a startup, and where these people are besides a profile search.

The sourcing kit

{{SOURCE}}

Paste this into the same conversation. It reads the decode you just got. You run the searches yourself — it never touches LinkedIn.

3Same chat, when you have someone

Score a candidate

Evidence for and against, real gaps versus imaginary ones, over-claims (a tool named with no project behind it), under-claims (a project described without naming the tool — the ones worth chasing), questions for this specific person, and the sentence to send the client.

The fit score

{{FIT}}

Paste this, then paste the candidate's CV or profile underneath. Their copy, your keystrokes — it never fetches anyone.

What it will not do

It never touches LinkedIn and never looks anyone up. It writes the search string; you run the search. Candidate profiles are pasted by you, never fetched. That is a line the kit does not cross, and it will say so if you ask it to.

A note on the fourth tool

There is a fourth pass — receipts, which reads what a candidate has actually built from their public GitHub. It is not here, because it has to fetch real data and this page will not fetch anything. It lives in the repo for anyone who wants to run it themselves.
